# 06) Lift the annotation onto the scaffolds

**Goal:** Update the GFF coordinates from the contig-level annotation to the scaffolded
coordinates.

**Rationale:** The annotation was generated against the corrected *contigs*. Because
scaffolding only reorders, reorients, and (in one case) breaks those contigs — it does not
alter their sequence — the annotation can be lifted onto the scaffolds arithmetically via
the AGP, with no need to re-run gene prediction. The liftover is then verified by
extracting CDS and transcript sequence from both coordinate systems and confirming they
are identical.

**Input:** `Kohalensis.contig_corrected.manual.chr_first.agp` from [05](05_Scaffolding_via_LinkageMaps.md), plus the contig-level annotation `Lkohalensis_braker_combined.emapper.decorated.gff`
**Output:** `Kohalensis_scaffolds.gff`

> [!NOTE]
> The contig-level annotation (`Lkohalensis_braker_combined.emapper.decorated.gff`) was
> generated by a collaborator and is an input to this repository, not a product of it.
> See [README.md](README.md#annotation).

---

## 1) Set up

```sh
mkdir -p ~/Kohalensis_Genome/05_Update_Gff
cd ~/Kohalensis_Genome/05_Update_Gff

# Add the agp file
cp ../04_Scaffold_Contigs/05_Generate_AGP/Kohalensis.contig_corrected.manual.chr_first.agp .
```

## 2) Lift the GFF using the AGP

RagTag's liftover script was tried first but does not handle the case where a contig has
been broken, which applies here (`ptg000005l_1` is split during scaffolding). The custom
script [scripts/agp_liftover_gff.py](scripts/agp_liftover_gff.py) handles the break by
mapping each feature onto the correct contig fragment and clipping to fragment bounds,
reversing coordinates and strand for fragments placed in `-` orientation.

```sh
python ../../scripts/agp_liftover_gff.py \
    Kohalensis.contig_corrected.manual.chr_first.agp \
    Lkohalensis_braker_combined.emapper.decorated.gff \
    Lkohalensis_braker_combined.emapper.decorated.SCAFFOLDS.gff
```

## 3) Sort and validate the GFF structure with AGAT

```sh
# Install (first time only)
source ~/Environments/miniconda3/bin/activate agat
conda create -n agat
conda activate agat
conda install -c bioconda agat

agat_convert_sp_gxf2gxf.pl --gff Lkohalensis_braker_combined.emapper.decorated.SCAFFOLDS.gff -o Kohalensis_scaffolds.gff
```

---

## 4) Verify the annotations carried over correctly

The check: extract CDS and transcript sequence using the *contig* annotation against the
*contigs*, and using the *scaffold* annotation against the *scaffolds*. If the liftover is
correct, the two sets of sequences must be identical.

```sh
source ~/Environments/miniconda3/bin/activate
conda create -n gffread
conda activate gffread
mamba install -c bioconda gffread
mamba install -c seqkit
mkdir ~/Kohalensis_Genome/05_Update_Gff/verifying
```

### 4.1 — Extract CDS/transcripts from the contig annotation

```sh
gffread -g ~/Kohalensis_Genome/04_Scaffold_Contigs/05_Generate_AGP/Kohalensis.contig_corrected.fa \
    -x verifying/Kohalensis.CONTIGS.cds.fa \
    -w verifying/Kohalensis.CONTIGS.transcripts.fa \
    Lkohalensis_braker_combined.emapper.decorated.gff
```

### 4.2 — Extract CDS/transcripts from the scaffold annotation

```sh
gffread -g ~/Kohalensis_Genome/04_Scaffold_Contigs/05_Generate_AGP/Kohalensis_corrected_man_scaffolds.fa \
    -x verifying/Kohalensis.SCAFFOLDS.cds.fa \
    -w verifying/Kohalensis.SCAFFOLDS.transcripts.fa \
    Kohalensis_scaffolds.gff
```

### 4.3 — Confirm there are no differences

```sh
cd verifying

# Check for differences in CDS
seqkit sort Kohalensis.CONTIGS.cds.fa > Kohalensis.CONTIGS.cds.sorted.fa
seqkit sort Kohalensis.SCAFFOLDS.cds.fa > Kohalensis.SCAFFOLDS.cds.sorted.fa
diff Kohalensis.CONTIGS.cds.sorted.fa Kohalensis.SCAFFOLDS.cds.sorted.fa
## Confirmed - no differences in the CDS

# Check for differences in transcripts
seqkit sort Kohalensis.CONTIGS.transcripts.fa > Kohalensis.CONTIGS.transcripts.sorted.fa
seqkit sort Kohalensis.SCAFFOLDS.transcripts.fa > Kohalensis.SCAFFOLDS.transcripts.sorted.fa
diff Kohalensis.CONTIGS.transcripts.sorted.fa Kohalensis.SCAFFOLDS.transcripts.sorted.fa
## Confirmed - no differences in transcripts
```

**Result:** CDS and transcript sequences are identical between the contig and scaffold
coordinate systems. The liftover is correct.

### 4.4 — Confirm the annotations are plausible genes

```sh
seqkit stats Kohalensis.SCAFFOLDS.transcripts.sorted.fa
# file                                        format  type  num_seqs      sum_len  min_len  avg_len    max_len
# Kohalensis.SCAFFOLDS.transcripts.sorted.fa  FASTA   DNA     31,039  224,302,519       12  7,226.5  1,183,350

# Check %N and unexpected bases
seqkit fx2tab -n -l -s Kohalensis.SCAFFOLDS.transcripts.sorted.fa | awk '{n+=gsub(/N/,"",$3)} END{print "Ns:",n}'
# Ns: 0
```

Coding potential was then assessed with TransDecoder, using DIAMOND and Pfam homology
evidence to retain genes with support — see
[scripts/check_coding_seq.sh](scripts/check_coding_seq.sh).
